# ต้นแบบ MMORPG บนเว็บบราวเซอร์ (ภาษาไทย)

เกมนี้เป็นต้นแบบเริ่มต้นสำหรับมือใหม่ มีแผนที่ 2D วาดด้วย Canvas, ผู้เล่นออนไลน์แบบเรียลไทม์ผ่าน Socket.IO, อาชีพ 3 แบบ, มอนสเตอร์, EXP/เลเวล, ทอง, ไอเทม, ยาฟื้นพลัง, ปุ่มสกิล, สร้างกิลด์, แลกเปลี่ยนทดลอง และ PvP แบบง่าย

## วิธีเปิดบนคอมพิวเตอร์

1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/
2. แตกไฟล์ ZIP นี้
3. เปิด Terminal / Command Prompt ในโฟลเดอร์ที่มี `package.json`
4. พิมพ์ `npm install`
5. พิมพ์ `npm start`
6. เปิดเบราว์เซอร์ไปที่ http://localhost:3000
7. เปิด URL เดียวกันในอีกแท็บหรืออีกเครื่องที่อยู่เครือข่ายเดียวกันเพื่อทดสอบผู้เล่นหลายคน

หากทดสอบจากมือถืออย่างเดียว สามารถใช้บริการโฮสต์ที่รองรับ Node.js ได้ แต่การติดตั้งแพ็กเกจและการจัดการไฟล์จะง่ายกว่าบนคอมพิวเตอร์

## นำขึ้นออนไลน์ (ภาพรวม)

1. สร้างบัญชีผู้ให้บริการโฮสต์ที่รองรับ Node.js และ WebSocket เช่น Render หรือ Railway
2. อัปโหลดโฟลเดอร์นี้เข้า GitHub repository
3. สร้าง Web Service จาก repository
4. ตั้ง Build Command เป็น `npm install` และ Start Command เป็น `npm start`
5. เมื่อโฮสต์ deploy สำเร็จ ให้เปิด URL HTTPS ที่ได้รับ
6. ทดสอบเปิดจากอุปกรณ์ 2 เครื่อง และตรวจว่าเชื่อมต่อ/เดิน/โจมตีได้

ค่าพอร์ตใช้ `process.env.PORT` แล้ว จึงรองรับโฮสต์ Node.js ทั่วไปที่กำหนดพอร์ตผ่าน environment variable

## สิ่งที่ยังเป็นเดโม ไม่ใช่เกมเปิดให้บริการจริง

- บัญชีเป็นเพียงการใส่ชื่อ ไม่มีระบบรหัสผ่าน/ยืนยันอีเมล
- ข้อมูลผู้เล่น ไอเทม ทอง และกิลด์เก็บในหน่วยความจำ รีสตาร์ตเซิร์ฟเวอร์แล้วหาย
- ระบบแลกเปลี่ยนเป็นตัวอย่างโอน 5 ทอง ไม่ใช่หน้าต่างแลกไอเทมเต็มรูปแบบ
- สกิลเป็นข้อความตัวอย่าง ยังไม่มีคูลดาวน์/มานา/เอฟเฟกต์จริง
- PvP ยังไม่มีสนามประลอง กติกา หรือระบบป้องกันโกงที่เพียงพอ
- ไม่มีระบบแอดมิน สำรองข้อมูล จำกัดอัตราการเรียก หรือการตรวจสอบความปลอดภัยระดับ production

## ก่อนเปิดให้ผู้เล่นจริง

เพิ่มฐานข้อมูลถาวร (เช่น PostgreSQL), ระบบบัญชีและ session ที่ปลอดภัย, ตรวจสอบทุกการกระทำฝั่งเซิร์ฟเวอร์, ระบบบันทึก/กู้คืนข้อมูล, rate limit, moderation, logging, backup และการทดสอบโหลด/ความปลอดภัยก่อนเปิดสาธารณะ

## โครงสร้างไฟล์

- `server.js` — เซิร์ฟเวอร์ Node.js + Socket.IO และกติกาเกมฝั่งเซิร์ฟเวอร์
- `public/index.html` — หน้าจอเกม
- `public/style.css` — รูปแบบหน้าจอ
- `public/game.js` — วาดแผนที่และรับอินพุตผู้เล่น
- `package.json` — รายการ dependencies และคำสั่งเริ่มเกม
